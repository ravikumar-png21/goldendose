GoldenDose · 8

Use the restaurant analogy. "What you saw in the demo is the frontend. Every tap becomes a request through the API. The backend is where the rules live: it refuses a double tap, refuses an undo after five minutes, and checks you only see your own family. The database remembers. Hosting is the building: today that's this laptop; next it's a service on the internet." The key idea: the backend enforces the rules, because anything on a phone can be tampered with.
