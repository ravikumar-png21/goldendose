What we built

Two apps, one shared record

For the elder

Kamala's app

  • One screen: today's medicines
  • Full-screen alarm that speaks
  • Big "Taken" button, with Undo
  • No password: paired with a code
  • Keeps working without internet

For the family

Priya's family app

  • Add medicines, times and photos
  • See today at a glance
  • 7-day history
  • Alerts by SMS, WhatsApp or app
  • Several elders, several carers
