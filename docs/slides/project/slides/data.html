GoldenDose · 10

"A database is a set of linked spreadsheets. Two tables are worth explaining. care_links answers 'can one carer look after two parents, and can a parent have two carers?' Yes to both, so instead of one column we keep a table of pairs: a 'join table'. dose_log is the record of truth, and the database itself refuses a duplicate for the same dose on the same day." Passwords are never stored, only a one-way scramble.
