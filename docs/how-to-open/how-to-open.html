GoldenDose · simple guide

How to open the app

GoldenDose has two parts. Priya's family app is for the person who sets up the medicines. Kamala's app is for the older person who takes them. Follow the steps in order.

1

Start the app (on the Mac)

  1. Press Cmd + Space together. A search box appears.
  2. Type Terminal, then press Return. A window with text opens.
  3. Type this line exactly (or copy it, then press Cmd + V to paste): cd ~/Documents/medstracker && npm run demo
  4. Press Return.
  5. Wait a few seconds. You will see "GoldenDose demo is ready" and an alarm time (⏰). Write down the alarm time.

Important: keep this Terminal window open the whole time. Closing it switches the app off. You can make it smaller, but don't close it.

2

Open Priya's family app

  1. Press Cmd + Space, type Safari, press Return.
  2. Press Cmd + L to go to the address bar at the top.
  3. Type this address, then press Return: localhost:3000/care/
  4. Click the Email box and type: priya@example.com
  5. Click the Password box and type: goldendose-demo
  6. Click the green Sign in button.

You should see "Hello, Priya" with Kamala and Ramesh.

3

Open Kamala's app

  1. In Safari, press Cmd + N to open a second window.
  2. Press Cmd + L, type this address, then press Return: localhost:3000
  3. You will see "Welcome to GoldenDose" and a box for a code.
4

Connect Kamala's app (a one-time code)

  1. Go back to Priya's window. Click Kamala.
  2. Scroll down. Click Get a connection code. Six numbers appear, like 774 543.
  3. Go to Kamala's window. Click the code box and type the six numbers.
  4. Click the green Connect button.
  5. Click once anywhere on Kamala's screen. This lets the alarm make a sound.

You should see "Good morning (or afternoon, or evening), Kamala" and her medicines.

The code works once and only for 15 minutes. If it says "That code didn't work", click Get a new code in Priya's window.

5

Watch the alarm ring

  1. Keep Kamala's window open and on the screen.
  2. Turn the Mac's volume up.
  3. At the alarm time you wrote down in step 1, the screen turns yellow, chimes, and reads the medicine aloud.
  4. Click the big green Taken button.
6

Optional: open Kamala's app on a real phone

  1. Connect the phone to the same Wi-Fi as the Mac.
  2. Look in the Terminal window for the line "On a phone (same Wi-Fi)". It shows an address like: http://192.168.43.84:3000/
  3. On the phone, open the browser (Safari or Chrome) and type that address.
  4. Connect it with a code, the same way as in step 4.
  5. Turn the phone's volume up. On an iPhone, turn off silent mode.
7

Switch the app off when finished

  1. Click on the Terminal window.
  2. Press Ctrl + C together. (Ctrl, not Cmd.)
  3. The app stops. You can now close Terminal and Safari.

If something goes wrong

What you seeWhat to do
Safari says it "can't connect to the server"The app is off. Do step 1 again.
Terminal says "GoldenDose is already running"It's already on. Go straight to step 2.
Terminal says "command not found"Check the line was typed exactly, including the spaces and &&.
"Email or password is wrong"Type them again: priya@example.com and goldendose-demo.
The alarm has no soundClick once on Kamala's screen. Turn the volume up.
The alarm time has passedPress Ctrl + C in Terminal, then do step 1 again. It sets a new alarm 5 minutes later.

Keys used in this guide

Cmd + SpaceOpen search, to find an app like Terminal or Safari
ReturnRun what you typed, or open what you searched for
Cmd + VPaste text you copied
Cmd + LJump to Safari's address bar
Cmd + NOpen a new Safari window
Cmd + RReload a page, to see the latest information
Cmd + +Make the page bigger, for people watching from far away
Ctrl + CIn Terminal: switch the app off

Each time you start the app with this command, the demo data starts fresh. Anything added earlier is cleared.
