# User test: the new family features (21 October 2026)

**Who tested:** Claude, acting as Priya (the daughter) and Kamala, on a phone-sized screen (375 × 812),
with the fresh demo data. This is a careful walk-through, **not** a session with a real older person or
caregiver. It catches confusing screens early; it does not replace watching real people
(see [USER-TESTING.md](USER-TESTING.md), which now has tasks for these features too).

## What was changed after the test

1. **Home page:** only urgent and today's problems are shown in full; the rest is one line per person
   ("2 more things worth a look for Kamala"), so the list of people stays in view.
2. **Clearer labels:** "Important" and "Soon" became **Today** and **Worth a look**.
3. **The Ask button** no longer covers the bottom of the page.
4. **Medicine meter:** a live line as you type ("20 tablets, 2 a day: about 10 days. Order by Mon 26 Oct"),
   a shorter explanation, and the order-by date on each medicine card.
5. **"Usually used for"** box hides once "What it's for" already says it.
6. **Doctor report on a phone:** one card per medicine, every number visible; still a proper table for screen readers.
7. **Ask:** understands everyday words (BP, sugar, cholesterol, thyroid, heart, bones, acidity, vitamin),
   answers "what changed?", and says dates like "Fri 16 Oct".
8. **Demo data:** the demo's Calcium now has "what it's for".

All automatic tests pass after the changes: backend 80, browser 32 (including the accessibility checks).

## Still worth testing with real people

- Do families want pattern messages on SMS/WhatsApp, or only in the app?
- Is "Approval" understood by families who share the care?
- Can an older person read "For: …" on their own phone, in their language?
