Questions to expect

Short, honest answers

How much will it cost to run?

On this laptop, nothing. Online: a hosting service plus a web address, a small monthly cost at this size. SMS and WhatsApp cost a little per message; app notifications are free. I'll bring compared options and exact prices.

Is health information safe?

Passwords are never stored, only a one-way scramble. Every request is checked so families only see their own people. Typed text can't be used to run code. Online, we add the HTTPS padlock and limits on password guessing.

Does it work on iPhone?

The web version works in any phone browser today. The phone apps will use Android's full-screen alarms and Apple's AlarmKit (iOS 26 and later) for alarms on a locked phone.

What if the internet is down?

Reminders still ring, because the list is saved on the phone. A tap made offline is kept and sent automatically when the internet returns.

Has a real older person used it?

Answer honestly. If you've run the user-testing session, share what you learned. If not: "That's the next step, and the script is ready."

Could we add other languages?

Yes. It's on the "later" list. The words on screen are kept separate from the logic, and read-aloud can use Indian-language voices.
